# Workout

App web para móvil y ordenador para planificar y apuntar entrenamientos de fuerza. Funciona en local en cada
dispositivo (también sin conexión) y, opcionalmente, guarda los datos en tu Google Drive para compartirlos entre dispositivos.

**No contiene datos personales**: solo el código. Tus datos quedan en tu dispositivo y, si lo eliges, en tu Drive.
